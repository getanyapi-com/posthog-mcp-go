# posthog-mcp-go

Community-maintained PostHog MCP analytics for the official
[`modelcontextprotocol/go-sdk`](https://github.com/modelcontextprotocol/go-sdk).

This project is maintained by [AnyAPI](https://getanyapi.com). It is not an
official PostHog package.

The public API and behavior are specified in [SPEC.md](SPEC.md). Implementation
is test-driven from pinned PostHog TypeScript and Python behavior.

## Status

Pre-release. Do not depend on this repository until its first tagged release.
